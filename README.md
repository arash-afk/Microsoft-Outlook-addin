How to install: Go to **https://aka.ms/olksideload** — this opens Outlook on the web and, after a few seconds, pops up the "Add-Ins for Outlook" dialog. Outlook on the web opens, then the Add-Ins for Outlook dialog appears after a few seconds. Microsoft Learn
In that dialog, select My add-ins.

Scroll to the Custom Addins section at the bottom → Add a custom add-in → Add from File. The Custom Addins section is at the bottom of the dialog box; select the Add a custom add-in link, and then select Add from File. Microsoft Learn
Pick the manifest.xml I gave you and accept the prompts.
